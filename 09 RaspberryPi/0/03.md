The ARM Cortex‑A72 is a high‑performance 64‑bit CPU core from ARM, introduced in 2015 as a successor to the Cortex‑A57 and
designed for mobile and embedded systems that run rich operating systems such as Android or Linux.
[arm](https://www.arm.com/products/silicon-ip-cpu/cortex-a/cortex-a72)

### Basic architecture and ISA

The Cortex‑A72 implements the ARMv8‑A 64‑bit instruction set and is a 3‑wide out‑of‑order superscalar core, meaning it can
decode and execute up to three instructions per cycle under ideal conditions. It includes integrated NEON SIMD and VFPv4
floating‑point units, hardware virtualization support, and the Thumb‑2 instruction‑set encoding for better code density.
[armbasedsolutions](https://armbasedsolutions.com/info-detail/features-of-high-performance-64-bit-arm-cortex-a72-processor)

### Micro‑architecture highlights

The core uses a 15‑stage pipeline that is shorter than the A57’s, which helps reduce power for the same workload and
frequency. It features an advanced branch predictor and aggressive data‑path optimizations, improving performance per cycle
and reducing wasted energy from mis‑predicted branches.
[tomshardware](https://www.tomshardware.com/reviews/arm-cortex-a72-architecture,4424.html)

### Cache and memory

Each Cortex‑A72 core has separate L1 caches (typically 48 KB instruction and 32 KB data) and is usually paired with 1–2 MB of
shared L2 cache per cluster. The architecture supports large physical address extensions (LPAE), enabling up to about 1 TB of
physical memory, and can scale to 4 cores in a single cluster. [en.wikipedia](https://en.wikipedia.org/wiki/ARM_Cortex-A72)

### Power, process, and efficiency

Originally designed to be used on 16/14 nm FinFET processes, the Cortex‑A72 achieves roughly 90% higher performance or 20%
lower power than the A57 in the same conditions, and at 16 nm FinFET it can reach around 2.5 GHz while staying within tight
power envelopes (roughly 750 mW per core). This makes it well suited for power‑efficient high‑performance applications such
as smartphones, tablets, and embedded devices.
[armbasedsolutions](https://armbasedsolutions.com/info-detail/features-of-high-performance-64-bit-arm-cortex-a72-processor)

### Typical uses and chips

The Cortex‑A72 appears in many SoCs such as Huawei’s Kirin 950, Qualcomm’s Snapdragon 650/652, and some Rockchip and Synopsys
designs used in tablets, networking gear, and industrial computers. It is also widely used in “big.LITTLE” configurations
with lower‑power Cortex‑A53 cores to balance performance and battery life in mobile and embedded systems.
