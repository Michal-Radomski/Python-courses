Node-RED is a flow-based, low-code programming tool for creating event-driven applications, especially for IoT, automation,
and data processing. It runs on Node.js and uses a visual web-based editor to wire together nodes that handle inputs,
processing, and outputs—no traditional coding required for basic flows.
[en.wikipedia](https://en.wikipedia.org/wiki/Node-RED)

## Programming Language

Node-RED itself uses JavaScript for custom logic within "function" nodes, but most programming happens visually by dragging
and connecting pre-built nodes. The runtime is built entirely on Node.js, making it lightweight for devices like Raspberry
Pi. [forums.raspberrypi](https://forums.raspberrypi.com/viewtopic.php?t=172890)

## Simple Example: DHT11 Dashboard

This flow reads from your DHT11 sensor (GPIO4, from prior context), processes data, and displays it on a dashboard. Install
Node-RED on Pi (`sudo npm install -g --unsafe-perm node-red`), then add these nodes via the editor (http://localhost:1880):

1. **Inject node** → triggers reading every 5s.
2. **rpi-dht22 node** (install via palette: search "node-red-contrib-dht-sensor") → set to DHT11, pin 4.
3. **Function node** (JavaScript code):
   ```javascript
   if (msg.payload) {
     let temp = msg.payload.temp;
     let hum = msg.payload.hum;
     msg.payload = `Temp: ${temp.toFixed(1)}°C, Humidity: ${hum.toFixed(1)}%`;
   }
   return msg;
   ```
4. **Dashboard gauge/text node** → outputs reading.
5. **Debug node** → console view.

Deploy, and view at http://<pi-ip>:1880/ui. Perfect for your Raspberry Pi + DHT11 setup—expands easily to LEDs or web APIs.
