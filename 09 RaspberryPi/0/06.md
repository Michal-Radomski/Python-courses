**libgpiod** is a modern C library for interacting with Linux GPIO character devices (/dev/gpiochip\*), replacing the
deprecated sysfs interface (/sys/class/gpio). It offers efficient, flexible GPIO control via ioctl calls, with bindings for
Python, Go, and other languages.
[wiki.friendlyelec](https://wiki.friendlyelec.com/wiki/index.php/GPIO_Programming:_Using_the_libgpiod_Library)

## Key Features

- Provides command-line tools like `gpiodetect` (lists GPIO chips), `gpioinfo` (shows line details), `gpioget`/`gpioset`
  (read/write values), and `gpiomon` (event monitoring). [acmesystems](https://www.acmesystems.it/gpiod)
- Supports multi-line operations, asynchronous event handling, and hardware independence across platforms like Raspberry Pi
  and BeagleBone. [gitbook.beagleboard](https://gitbook.beagleboard.org/books/beaglebone-cookbook/02sensors/code/gpiod)
- Python bindings (`gpiod` on PyPI) simplify use without system dependencies. [pypi](https://pypi.org/project/gpiod/)

## Compared to RPi.GPIO/GPIO Zero

Unlike RPi.GPIO's sysfs reliance or GPIO Zero's high-level abstractions, libgpiod uses the faster character device API for
better performance in multi-pin or real-time scenarios. [blokas](https://blokas.io/pisound-micro/docs/gpiod-libgpiod/)
