You can program Raspberry Pi GPIO with Node.js using libraries like `onoff`, `node-libgpiod`, or `rpi-gpio`, which provide
access to pins for input/output just like Python libraries do.
[w3schools](https://www.w3schools.com/nodejs/nodejs_raspberrypi_gpio_intro.asp)

## Popular Node.js Libraries

- **onoff**: Simple for basic digital I/O; install via `npm install onoff`. Works on most Pi models.
  [stackoverflow](https://stackoverflow.com/questions/78173749/use-raspberry-pi-4-gpio-with-node-js)
- **node-libgpiod**: Modern choice for Pi 5+ using Linux's gpiod interface; requires `sudo apt install libgpiod-dev` first.
  [blog.arduino](https://blog.arduino.cc/2025/02/05/control-your-raspberry-pi-gpio-with-arduino-cloud-using-node-js-part-iii/)
- **rpi-gpio**: Uses physical pin numbering for easy wiring reference.
  [robert-drummond](https://robert-drummond.com/2013/06/06/raspberry-pi-gpio-inputoutput-in-javascript/)

## Example with onoff (LED Blink)

Connect an LED to GPIO 17 (physical pin 11) with a resistor to GND. Run as root or add user to gpio group.

```javascript
const Gpio = require("onoff").Gpio;
const led = new Gpio(17, "out"); // GPIO17 output

setInterval(() => {
  led.writeSync(led.readSync() === 0 ? 1 : 0); // Toggle
}, 500);

process.on("SIGINT", () => {
  led.writeSync(0);
  led.unexport();
  process.exit();
});
```

This blinks the LED every 500ms; handles cleanup on exit.
[w3schools](https://www.w3schools.com/nodejs/nodejs_raspberrypi_gpio_intro.asp)

## DHT11 with Node.js

From prior DHT11 wiring (GPIO4), use `npm install dht11-rpi` or similar, but `node-dht-sensor` is common:

```javascript
var sensor = require("node-dht-sensor");
sensor.read(11, 4, function (err, temperature, humidity) {
  if (!err) {
    console.log(`Temp: ${temperature}°C, Humidity: ${humidity}%`);
  }
});
```

Supports DHT11/22; runs periodically. [randomnerdtutorials](https://randomnerdtutorials.com/raspberry-pi-dht11-dht22-python/)

Node.js GPIO is performant for web servers or real-time apps, though some libraries need root access.
[github](https://github.com/jperkin/node-rpio)
