To securely insert secret values (like API keys or passwords) into a Python file, avoid hardcoding them directly—instead load
them from external sources like environment variables or .env files. This keeps sensitive data out of version control and
source code. [blog.gitguardian](https://blog.gitguardian.com/how-to-handle-secrets-in-python/)

## Environment Variables

Set secrets as OS environment variables (e.g., via `export API_KEY=your_secret` in terminal or system settings), then access
them in Python.

```python
import os

api_key = os.environ.get('API_KEY')
if api_key:
    print(f"Using key: {api_key[:5]}...")
else:
    raise ValueError("API_KEY not set")
```

This method is simple and secure for production, as values stay outside the code.
[youtube](https://www.youtube.com/watch?v=fBECUO9StMM)

## .env Files (Recommended)

Use a `.env` file for local development—add it to `.gitignore`. Install `pip install python-dotenv`, create `.env` with
`API_KEY=your_secret`, and load it.

```python
from dotenv import load_dotenv
import os

load_dotenv()  # Loads .env into environment variables
api_key = os.getenv('API_KEY')
```

Multiple environments work too (e.g., `.env.dev`). This is the most common beginner-friendly approach.
[beaglesecurity](https://beaglesecurity.com/blog/article/secrets-in-python.html)

## JSON Config File

Store in a `secrets.json` file (also `.gitignore` it) like `{"api_key": "your_secret"}`.

```python
import json

with open('secrets.json') as f:
    secrets = json.load(f)
api_key = secrets['api_key']
```

Less ideal than .env for simplicity, but structured for complex configs.
[blog.gitguardian](https://blog.gitguardian.com/how-to-handle-secrets-in-python/)

## Best Practices

- Never commit secrets to Git—scan code with tools like GitGuardian.
- For cloud/production, use services like AWS Secrets Manager or HashiCorp Vault.
- Generate secrets securely with `secrets` module: `import secrets; token = secrets.token_hex(32)`.
  [docs.python](https://docs.python.org/3/library/secrets.html)
