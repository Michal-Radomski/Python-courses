Connecting the DHT11 temperature and humidity sensor to a Raspberry Pi is straightforward using GPIO pins. It requires a
pull-up resistor (typically 4.7k-10kΩ) between power and data pins for reliable communication.
[pimylifeup](https://pimylifeup.com/raspberry-pi-dht11-sensor/)

## DHT11 Pin Functions

The DHT11 has four pins (some modules combine or omit pin 3):

| Pin | Function | Description                                                                                                                  |
| --- | -------- | ---------------------------------------------------------------------------------------------------------------------------- |
| 1   | VCC      | Power input (3.3V or 5V from Pi). [pimylifeup](https://pimylifeup.com/raspberry-pi-dht11-sensor/)                            |
| 2   | DATA     | Digital signal for reading temp/humidity (connects to GPIO). [pimylifeup](https://pimylifeup.com/raspberry-pi-dht11-sensor/) |
| 3   | NC       | Not connected (unused). [pimylifeup](https://pimylifeup.com/raspberry-pi-dht11-sensor/)                                      |
| 4   | GND      | Ground connection. [pimylifeup](https://pimylifeup.com/raspberry-pi-dht11-sensor/)                                           |

This wiring diagram shows a typical setup with jumper wires on a breadboard.
[pimylifeup](https://pimylifeup.com/raspberry-pi-dht11-sensor/)

## Wiring Steps

Connect as follows (using GPIO4, common choice):

- DHT11 Pin 1 (VCC) → Raspberry Pi 3.3V (Physical Pin 1).
- DHT11 Pin 2 (DATA) → GPIO4 (Physical Pin 7) + 5kΩ pull-up resistor to Pin 1.
- DHT11 Pin 4 (GND) → Raspberry Pi GND (Physical Pin 6).

Power off Pi before wiring. Modules often include the resistor onboard.
[pimylifeup](https://pimylifeup.com/raspberry-pi-dht11-sensor/)

## Python Example

Install Adafruit library: `sudo pip3 install Adafruit_DHT`. Then read data:

```python
import Adafruit_DHT

sensor = Adafruit_DHT.DHT11
pin = 4  # GPIO4

humidity, temperature = Adafruit_DHT.read_retry(sensor, pin)
if humidity is not None and temperature is not None:
    print(f'Temp: {temperature:0.1f}°C, Humidity: {humidity:0.1f}%')
```

Readings update every 1-2 seconds; retries handle timing issues.
