`sqlite:///data.db` is a URI string used by SQLAlchemy (and similar libraries like Alembic) to specify a SQLite database
connection.

## Breakdown

The format follows the scheme `dialect://[username]:[password]@[host]:[port]/[path]`, where `sqlite:///data.db` indicates:

- `sqlite://`: The dialect for SQLite, a lightweight file-based database.
- `data.db`: Relative path to the database file in the current working directory.

## Usage Context

In Pytest fixtures or Flask/Django apps, this creates/connects to `data.db` on disk for testing or development. Absolute
paths use `sqlite:////absolute/path/to/data.db` (four slashes).[2]

## Example

```python
from sqlalchemy import create_engine
engine = create_engine('sqlite:///data.db')
```

This initializes a SQLite database file named `data.db`.[2]
