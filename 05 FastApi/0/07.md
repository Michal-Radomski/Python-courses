`from typing import Annotated, Literal` imports two type hint utilities from Python's `typing` module for advanced
annotations. `Annotated` attaches metadata to types for tools like validators, while `Literal` restricts values to specific
literals.

## Annotated Purpose

Annotated combines a base type with extra information, such as validation rules or descriptions, without altering runtime
behavior.[1][3] Libraries like Pydantic or FastAPI interpret this metadata for features like field constraints.[5][1]
Example: `Annotated[int, Field(gt=0)]` marks an integer greater than zero.[1]

## Literal Purpose

Literal specifies that a value must match exact literals, like strings or numbers, aiding static checkers like mypy.[7][8] It
supports primitives: `Literal["active", "inactive"]` or `Literal[1, 2, 3]`.  
Unions combine them, e.g., `Union[Literal["red"], Literal["blue"]]`.[7]
