`@pytest.mark.anyio` is a pytest marker decorator from the AnyIO library that enables async test functions to run properly in
a pytest environment. It automatically provides an AnyIO backend fixture, allowing asynchronous code to execute with support
for multiple event loop backends like asyncio or Trio.

## Purpose

This marker treats async def test functions as valid pytest tests by injecting the `anyio_backend` fixture, which sets up the
necessary async context.[3][5] Without it, pytest would fail to handle coroutines directly, similar to how
`@pytest.mark.asyncio` works for asyncio-only tests.[4] It's ideal for libraries or tests needing backend-agnostic async
support.

## Usage Examples

Apply to individual tests:

```python
@pytest.mark.anyio
async def test_async_function():
    await some_async_call()
```

Apply module-wide:

```python
pytestmark = pytest.mark.anyio  # Affects all tests in the module
async def test_something():
    ...
```

Alternatives include directly using the `anyio_backend` fixture in test parameters.[3]
