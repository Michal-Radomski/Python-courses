Python's List, Tuple, Dictionary, and Set have distinct characteristics for different use cases.

## Key Differences Table

| Feature        | List `[]`   | Tuple `()`  | Set `{}`       | Dictionary `{:}`        |
| -------------- | ----------- | ----------- | -------------- | ----------------------- |
| **Mutable**    | ✅ Yes      | ❌ No       | ✅ Yes         | ✅ Yes (keys immutable) |
| **Ordered**    | ✅ Yes      | ✅ Yes      | ❌ No          | ✅ Yes (3.7+)           |
| **Duplicates** | ✅ Allowed  | ✅ Allowed  | ❌ Unique only | Keys: ❌ Values: ✅     |
| **Indexed**    | ✅ `lst[0]` | ✅ `tup[0]` | ❌ No          | ✅ `dict['key']`        |
| **Syntax**     | `[1,2,3]`   | `(1,2,3)`   | `{1,2,3}`      | `{'a':1,'b':2}`         |

## Usage Examples

```python
# List - ordered, mutable collection
fruits = ['apple', 'banana', 'apple']
fruits.append('orange')
fruits[1] = 'kiwi'

# Tuple - immutable, fixed data (faster, hashable)
point = (3, 4)  # coordinates
# point[0] = 5  # Error!

# Set - unique items, fast membership testing
unique_ids = {1, 2, 2, 3}  # {1, 2, 3}
unique_ids.add(4)

# Dictionary - key-value pairs, fast lookups
user = {'name': 'Alice', 'age': 30}
user['city'] = 'NYC'
print(user['name'])  # Alice
```

## When to Use Each

- **List**: Ordered collections that change (shopping cart, results)
- **Tuple**: Fixed data, function returns, dictionary keys
- **Set**: Remove duplicates, membership tests, set operations
- **Dictionary**: Map keys to values (configs, JSON data, caches)

**Memory tip**: Lists/Tuples = sequences (order matters), Sets/Dicts = mappings (relationships matter).[1][4]
