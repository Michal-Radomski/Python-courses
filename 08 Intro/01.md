Python complex numbers use the syntax `a + bj` where `a` is the real part and `b` is the imaginary part (`j` represents √-1).

## Basic Creation

```python
# Direct literal
z1 = 3 + 4j
print(z1)        # (3+4j)
print(type(z1))  # <class 'complex'>

# Using complex() function
z2 = complex(3, 4)
print(z2)        # (3+4j)

# Real part only
z3 = complex(5)  # (5+0j)
```

## Common Operations

```python
z1 = 3 + 4j
z2 = 1 - 2j

print(z1 + z2)  # (4+2j)
print(z1 * z2)  # (11+2j)
print(z1 / z2)  # (2.2+2.8j)
print(abs(z1))  # 5.0 (magnitude)

# Access parts
print(z1.real)  # 3.0
print(z1.imag)  # 4.0
print(z1.conjugate())  # (3-4j)
```

## Practical Example

```python
import cmath

z = 3 + 4j
print(f"Magnitude: {abs(z):.1f}")           # 5.0
print(f"Phase: {cmath.phase(z):.2f} rad")   # 0.93 radians
print(f"Polar form: {cmath.polar(z)}")      # (5.0, 0.9272952180016122)
```

`cmath` is Python's built-in module for mathematical functions on complex numbers.

## Purpose

The `cmath` module extends `math` functions to handle complex numbers, providing `sin()`, `cos()`, `sqrt()`, `log()`, etc.
for `3+4j` values that `math` cannot process.

## Key Functions

```python
import cmath

z = 3 + 4j

print(cmath.sqrt(z))     # (2+1j) - complex square root
print(cmath.sin(z))      # (3.8537-27.0168j)
print(cmath.phase(z))    # 0.9273 radians (angle)
print(cmath.polar(z))    # (5.0, 0.9273) - (magnitude, angle)
print(cmath.rect(5, 0.9273))  # Converts back to (3+4j)
```

## Common Constants

| Constant     | Value            |
| ------------ | ---------------- |
| `cmath.pi`   | 3.14159...       |
| `cmath.e`    | 2.71828...       |
| `cmath.infj` | Complex infinity |

## When to Use

- Use `math` for real numbers only
- Use `cmath` for any complex math operations
- Built into Python (no install needed)

Example: Solve quadratic equations with complex roots or signal processing where `sqrt(-1)` appears naturally.[2][3]

JavaScript/TypeScript handles complex numbers through the built-in `Complex` class (ES2025+) or `std::Complex` in TypeScript
with Node.js.

## Native JavaScript (ES2025+)

```javascript
// Direct literal syntax
const z1 = 3n + 4n * 1n ** 0.5n;  // 3 + 4i (BigInt complex)
const z2 = Complex(3, 4);          // Standard complex

console.log(z1.re);    // 3n
console.log(z1.im);    // 4n
console.log(z1.abs()); // 5n

// Operations
const sum = z1 + z2;   // Complex addition
const prod = z1 * z2;  // (11 + 2i)
```

## Node.js with `complex.js` Library (Most Common)

```bash
npm install complex.js
```

```javascript
// TypeScript types available
import Complex from "complex.js";

const z1 = new Complex(3, 4);
const z2 = new Complex(1, -2);

console.log(z1.add(z2).toString()); // (4 + 2i)
console.log(z1.mul(z2).toString()); // (11 + 2i)
console.log(z1.abs()); // 5
console.log(z1.arg()); // 0.927 radians

// Polar conversion
const polar = z1.toPolar();
console.log(polar.r, polar.phi); // 5, 0.927
```

## TypeScript Interface

```typescript
import Complex from "complex.js";

interface ComplexMath {
  z: Complex;
  magnitude(): number;
  phase(): number;
}

const calc: ComplexMath = {
  z: new Complex(3, 4),
  magnitude() {
    return this.z.abs();
  },
  phase() {
    return this.z.arg();
  },
};
```

## Key Methods Comparison

| Operation   | Python `cmath` | JS `complex.js` |
| ----------- | -------------- | --------------- |
| Magnitude   | `abs(z)`       | `z.abs()`       |
| Phase       | `phase(z)`     | `z.arg()`       |
| Square Root | `sqrt(z)`      | `z.sqrt()`      |
| Sine        | `sin(z)`       | `z.sin()`       |
