JavaScript and TypeScript have a direct equivalent to Python's `@staticmethod` via the `static` keyword on methods, but no
built-in equivalent to `@classmethod`, which receives the class as its first argument.

## Static Methods (Matches @staticmethod)

Static methods belong to the class itself, not instances, and are called directly on the class without `this` referring to an
instance.

```typescript
class MathUtils {
  static add(a: number, b: number): number {
    return a + b; // No access to instance properties
  }
}

console.log(MathUtils.add(2, 3)); // 5 [web:21][web:23]
```

## Class Methods Approximation

For `@classmethod`-like behavior (accessing the class type), use a static factory method with `new.target` (ES2015+) or
generics:

```typescript
class Point {
  constructor(public x: number, public y: number) {}

  static fromArray(cls: typeof Point, coords: [number, number]): Point {
    return new cls(coords[0], coords[1]); // cls acts like 'cls' in @classmethod
  }
}

const p1 = Point.fromArray(Point, [1, 2]); // Point(1, 2)
```

This pattern enables subclassing: `class Vector extends Point {}; const v = Vector.fromArray(Vector, [3, 4]);`. Use
namespaces or object literals for pure utilities without inheritance.[2][4][5]
