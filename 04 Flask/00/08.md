SQLAlchemy is a popular Python SQL toolkit and Object-Relational Mapper (ORM) that simplifies database interactions by
allowing developers to work with Python classes instead of raw SQL queries. It supports multiple databases like PostgreSQL,
MySQL, and SQLite through its Core layer for SQL expressions and ORM for object mapping.[1][2][3]

## Core Features

SQLAlchemy's ORM maps Python classes to database tables, handling CRUD operations, relationships, and migrations
automatically. Key capabilities include connection pooling, eager loading to avoid N+1 queries, and support for raw SQL when
needed.[2][4]

## Flask Integration

Flask integrates SQLAlchemy via the Flask-SQLAlchemy extension, which configures the engine and sessions within Flask apps.
Install with `pip install Flask-SQLAlchemy`, then initialize in your app:[6]

```python
from flask import Flask
from flask_sqlalchemy import SQLAlchemy

app = Flask(__name__)
app.config['SQLALCHEMY_DATABASE_URI'] = 'sqlite:///example.db'
db = SQLAlchemy(app)
```

Define models as classes inheriting from `db.Model`, such as
`class User(db.Model): id = db.Column(db.Integer, primary_key=True)`. Use `db.session` for queries like
`db.session.add(user); db.session.commit()` in routes.[5][6]
