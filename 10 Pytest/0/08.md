Here are the most commonly used `pytest` command‑line options you’ll actually reach for in daily work.

### Basic test selection and running

- Run all tests in the current directory:

  ```bash
  pytest
  ```

- Run tests in a specific file:

  ```bash
  pytest test_example.py
  ```

- Run tests in a directory:

  ```bash
  pytest tests/
  ```

- Run a specific test function:
  ```bash
  pytest test_example.py::test_something
  ```

### Output and verbosity

- More verbose output (show test names):

  ```bash
  pytest -v
  ```

- Show print/logging output in the console:

  ```bash
  pytest -s
  ```

- Combine verbose and output:

  ```bash
  pytest -vs
  ```

- Short summary (dots):
  ```bash
  pytest -q
  ```

[realpython](https://realpython.com/pytest-python-testing/)

### Filtering and selecting tests

- Run tests whose names match a keyword:

  ```bash
  pytest -k "login"        # tests containing "login"
  pytest -k "not slow"     # exclude tests marked "slow"
  ```

- Run only tests with a custom marker:

  ```bash
  pytest -m sanity
  pytest -m "not sanity"
  ```

- Show full help (all options and config flags):
  ```bash
  pytest -h
  pytest --help
  ```

[docs.pytest](https://docs.pytest.org/en/6.2.x/usage.html)

### Stopping, failing, and debugging

- Stop on first failure:

  ```bash
  pytest -x
  ```

- Stop after `n` failures:

  ```bash
  pytest --maxfail=2
  ```

- Start the debugger (e.g., `pdb` style) on failure:

  ```bash
  pytest --pdb
  pytest --pdb --tb=short
  ```

- Run only tests that previously failed:
  ```bash
  pytest --lf
  ```

[adamj](https://adamj.eu/tech/2019/10/03/my-most-used-pytest-commandline-flags/)

### Coverage‑like and extra info

- Show which tests were collected:

  ```bash
  pytest --collect-only
  ```

- Show available fixtures:

  ```bash
  pytest --fixtures
  ```

- Show warnings (helpful to catch flaky/mismatch issues):
  ```bash
  pytest -W default
  ```
