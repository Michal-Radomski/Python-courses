To run `pytest`, you need `pytest` installed and a project layout with test files (usually prefixed or suffixed with `test_`
or `_test`). [docs.pytest](https://docs.pytest.org/en/stable/getting-started.html)

### Basic setup

1. Install `pytest` (if not already installed):

   ```bash
   pip install pytest
   ```

2. Put your tests in files like `test_xxx.py` or `xxx_test.py` next to your code or in a `tests/` directory.
   [realpython](https://realpython.com/pytest-python-testing/)

### Running tests

From your project root (or the directory that contains your test files), run:

- All tests in the current project:

  ```bash
  pytest
  ```

  This automatically discovers and runs all tests that match the naming pattern.
  [docs.pytest](https://docs.pytest.org/en/stable/how-to/usage.html)

- Only tests in a specific file:

  ```bash
  pytest tests/test_example.py
  ```

- Only tests in a directory:

  ```bash
  pytest tests/
  ```

- One specific test function:
  ```bash
  pytest tests/test_example.py::test_something
  ```
  This runs only the `test_something` function inside `test_example.py`.
  [freecodecamp](https://www.freecodecamp.org/news/how-to-use-pytest-a-guide-to-testing-in-python/)

### Common useful options

- Show print output / print debugging:

  ```bash
  pytest -sv
  ```

- Stop after the first failing test:

  ```bash
  pytest -x
  ```

- Run tests in verbose mode (show more detail):
  ```bash
  pytest -v
  ```
