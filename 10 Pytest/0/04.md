Yes, you should install and import `pytest` if you want to use `pytest`‑style tests. In practice, almost all projects using
`pytest` just install it with `pip` and then use it from the command line; you **don’t need to `import pytest`** inside
simple test functions unless you use advanced features like fixtures or decorators.
[geeksforgeeks](https://www.geeksforgeeks.org/python/getting-started-with-pytest/)

### Example of a `pytest` test

Create a file called `test_example.py`:

```python
# content of test_example.py

def add(x, y):
    return x + y


def test_add_positive():
    assert add(2, 3) == 5


def test_add_negative():
    assert add(-1, 1) == 0


def test_add_zero():
    assert add(0, 0) == 0
```

Each test is just a normal function whose name starts with `test_`, and you use plain `assert` to check expectations.
[docs.pytest](https://docs.pytest.org/en/stable/getting-started.html)

### How to run this `pytest` test

1. Install `pytest` (once):

   ```bash
   pip install pytest
   ```

2. Run all tests in the current directory:

   ```bash
   pytest
   ```

   Or more verbosely:

   ```bash
   pytest -v
   ```

This will discover and run all `test_*.py` files and `test_*` functions automatically.
[semaphore](https://semaphore.io/community/tutorials/testing-python-applications-with-pytest)
