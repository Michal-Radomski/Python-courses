In Python, “packing” means collecting multiple values into a single variable (usually a tuple, list, or dict), and
“unpacking” means spreading a single iterable or mapping back out into multiple variables or arguments. JavaScript/TypeScript
have the same core idea, but the syntax is called array/object destructuring and the spread/rest operators rather than
“packing/unpacking.”[1][2][3][4]

## Python: packing and unpacking

- Packing:
  - Multiple values assigned to one variable automatically form a tuple: `t = 1, 2, 3` packs three values into `t`.[3]
  - In function parameters, `*args` packs extra positional arguments into a tuple and `**kwargs` packs extra keyword
    arguments into a dict.[7][1]
- Unpacking:
  - On the left‑hand side, Python unpacks an iterable into variables: `a, b, c = t` assigns the elements of `t` to `a`, `b`,
    and `c`.[3][7]
  - The `*` and `**` operators in calls and literals unpack containers: `f(*args, **kwargs)` spreads a tuple and dict into
    separate positional and keyword arguments, and `[0, *some_list, 99]` unpacks list items into a new list.[1][7]

## JS/TS equivalent concepts

In JavaScript and TypeScript, the closest equivalents are destructuring and the spread/rest syntax, which conceptually match
Python’s unpacking and packing.[2][4]

- Array and object destructuring:
  - `const [a, b] = arr;` and `const { x, y } = obj;` unpack array or object properties into separate variables, like
    `a, b = seq` or `x, y = mapping[...]` in Python.[4][2]
- Spread (`...`) and rest (`...`):
  - In function parameters, `function f(...args) {}` collects extra arguments into an array, similar to Python’s `*args`
    packing.[2][4]
  - In calls and literals, `f(...arr)` or `{ ...obj, extra: 1 }` spread an array or object out into separate arguments or
    properties, like `f(*seq, **mapping)` or `{**d, "extra": 1}` in Python.[4][2]

## Side‑by‑side overview

| Concept             | Python term | Python syntax example               | JS/TS term         | JS/TS syntax example                  |
| ------------------- | ----------- | ----------------------------------- | ------------------ | ------------------------------------- |
| Collect extras      | Packing     | `def f(*args, **kwargs): ...`[1][3] | Rest parameters    | `function f(...args) {}`[2][4]        |
| Break into vars     | Unpacking   | `a, b = seq`[3][7]                  | Destructuring      | `const [a, b] = arr;`[2][4]           |
| Spread into call    | Unpacking   | `f(*seq, **mapping)`[1][7]          | Spread in call     | `f(...arr)`[2][4]                     |
| Spread into literal | Unpacking   | `[0, *seq, 99]` or `{**d}`[1][7]    | Spread in literals | `[0, ...arr, 99]`, `{ ...obj }`[2][4] |

Terminology differs, but if you think of Python’s `*`/`**` as “pack/unpack operators,” the JS/TS equivalents are `...` used
as rest (packing) and spread (unpacking), plus destructuring assignment for variable binding.[2][4]
