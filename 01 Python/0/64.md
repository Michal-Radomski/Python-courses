In Python, the equivalent of an `index.js` file (the standard entry point in Node.js projects) is typically `main.py`.

## Entry Point Conventions

Python applications and packages use these common entry point files, depending on the context:

- **Standalone scripts**: `main.py` or `app.py`
- **Flask/Django web apps**: `app.py` or `wsgi.py`
- **FastAPI apps**: `main.py`
- **Poetry/Pipenv projects**: `pyproject.toml` specifies `main = "src.myapp.main:main"` or similar
- **Executable scripts**: Any `.py` file marked with `#!/usr/bin/env python` shebang

## Running the Equivalent

```bash
# Node.js: node index.js
node index.js

# Python equivalents:
python main.py
python app.py
uvicorn main:app --reload  # For FastAPI
flask run  # With FLASK_APP=app.py
```

## Project Structure Comparison

```
my-js-project/
├── index.js          # Entry point
├── package.json
└── src/

my-py-project/
├── main.py           # Entry point (Python equivalent)
├── pyproject.toml    # Metadata (like package.json)
└── src/
```

## Framework-Specific Equivalents

| Framework  | index.js equivalent                 |
| ---------- | ----------------------------------- |
| Express.js | `main.py` or `app.py`               |
| Next.js    | `main.py` + ASGI server             |
| FastAPI    | `main.py`                           |
| Flask      | `app.py`                            |
| Django     | `manage.py` (CLI entry) + `wsgi.py` |

Use `main.py` for most new Python projects to mirror `index.js` conventions. Tools like Poetry, Hatch, and modern
`pyproject.toml` setups recognize it automatically.[1][2]
