**Modules**  
A module in Python is a single `.py` file containing code like functions, classes, and variables that can be imported for
reuse. For example, `math.py` becomes a module when you run `import math`. Modules help organize code but cannot contain
submodules on their own.
[stackoverflow](https://stackoverflow.com/questions/7948494/whats-the-difference-between-a-module-and-package-in-python/49420164)

**Packages**  
A package is a directory of modules with an `__init__.py` file (which can be empty) to tell Python it's a package. This
enables hierarchical organization, like `from mypackage.submodule import func`. All packages are technically modules, but
only those with a `__path__` attribute qualify as packages.
[geeksforgeeks](https://www.geeksforgeeks.org/python/what-is-the-difference-between-pythons-module-package-and-library/)
